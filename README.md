# Bo7 website rebuild

The bo7.ie website (semi-private personal training, Blackrock and Killiney). Repo `bo7-gym/bo7-site`, published with GitHub Pages.

- `site/` — the website. No build step; GitHub Pages serves this folder at https://bo7.ie.
- `reference/` — internal pages kept as design references (plan, playbook, dashboard and members mockups, email). Not published.
- `source/` — content pulled from the current site (copy, inventory). Originals and videos are kept out of git.
- `AUDIT.md` — what was wrong with the old site and the plan.
- `HANDOVER-NOTES.md` — differences versus the old site and things to fix on their side.
